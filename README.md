 **Простое консольное приложение для работы с данными пациентов (парсинг c++)**  

 Что делает приложение
- Парсит файл patients.txt: разбивает строки по табуляции на поля, ФИО по пробелам, дату по точкам, заполняет структуры и сохраняет в вектор
- Предоставляет меню: просмотр всех пациентов, добавление нового, фильтрация иногородних, поиск по возрасту и диагнозу


Навыки  
- Работа со структурами (struct) и перечислениями (enum)
- Парсинг строк с помощью stringstream
- Хранение данных в векторах, файлах (vector)
- Цепочки вызовов методов (fluent interface)
- Чтение и запись в файлы (ifstream/ofstream)
- Валидация ввода (проверка на цифры, диапазоны)
- Работа с датой и временем (time, localtime)
